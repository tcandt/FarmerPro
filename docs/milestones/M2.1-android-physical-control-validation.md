## Reconnect Scenario

```text
old session A connected
connection lost
new session B becomes owner
inject command belonging to A
MUST reject with stale_session or stale_connection
```

## Server Restart Scenario

```text
epoch A seq 900
server restart
epoch B seq 1
agent accepts epoch B
late epoch A command arrives
MUST reject with stale_epoch
```
