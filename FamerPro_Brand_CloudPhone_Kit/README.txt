FamerPro Cloud-Phone Brand Kit

Cấu trúc:
00_MASTER_BOARDS        - Các board tổng thể mới nhất
01_LOGOS                - Logo chính, stacked, icon-only
02_APP_ICON_FAVICON     - App icon, adaptive icon, favicon, small-size icon
03_WEB_ANDROID_MOCKUPS  - Web header, landing, dashboard, launcher, splash mockups
04_GUIDELINES_SECTIONS  - Màu sắc, typography, clear-space, usage guide

Lưu ý:
- Các file hiện tại là PNG/raster được tách từ brand board đã tạo.
- Đây chưa phải bộ vector/source layer (SVG/AI/Figma).
- Nếu cần production asset chuẩn Android/Web, bước tiếp theo nên dựng lại logo master dưới dạng SVG,
  rồi export adaptive icon Android (foreground/background), favicon .ico và PNG chuẩn nhiều kích thước.
